<objective>
Import external plan files into the Ferrox planning system with conflict detection against PROJECT.md decisions.

- **--from**: Import an external plan file, detect conflicts, write as Ferrox PLAN.md, validate via ferrox-plan-checker.
- **--from-ferrox2**: Reverse-migrate a Ferrox-2 project (`.ferrox/` directory) back to Ferrox v1 (`.planning/`) format. Runs `ferrox-tools.cjs from-ferrox2`. Pass `--path <dir>` to migrate a project at a different path.
</objective>
