**Ferrox — top commands**

```text
/ferrox:new-project           Initialize a project (greenfield)
/ferrox:onboard               Onboard an existing codebase (brownfield)
/ferrox:map-codebase          Refresh/map codebase intelligence
/ferrox:plan-phase <N>        Create a phase plan
/ferrox:execute-phase <N>     Execute a phase
/ferrox:progress              Where am I, what's next
/ferrox:quick                 Small ad-hoc task with Ferrox guarantees
/ferrox:fast "<task>"         Trivial inline task — no subagents
/ferrox:debug "<symptom>"     Persistent debug session (survives /clear)
/ferrox:capture               Save an idea / todo / note
/ferrox:ship <N>              Open a PR from a completed phase
```

More: `/ferrox:help` (default tour) · `/ferrox:help --full` (everything) · `/ferrox:help <topic>` (one section)
