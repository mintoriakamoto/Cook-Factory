## 2. Display

**If `workspace_count` is 0:**

```
No workspaces found in ~/ferrox-workspaces/

Create one with:
  /ferrox:workspace --new --name my-workspace --repos repo1,repo2
```

Done.

**If workspaces exist:**

Display a table:

```
Ferrox Workspaces (~/ferrox-workspaces/)

| Name | Repos | Strategy | Ferrox Project |
|------|-------|----------|-------------|
| feature-a | 3 | worktree | Yes |
| feature-b | 2 | clone | No |

Manage:
  cd ~/ferrox-workspaces/<name>     # Enter a workspace
  /ferrox:workspace --remove <name>  # Remove a workspace
```

For each workspace, show:
- **Name** — directory name
- **Repos** — count from init data
- **Strategy** — from WORKSPACE.md
- **Ferrox Project** — whether `.planning/PROJECT.md` exists (Yes/No)
